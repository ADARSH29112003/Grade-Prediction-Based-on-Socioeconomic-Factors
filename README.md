# Grade Prediction Based on Socioeconomic Factors

## Project Overview

This project analyzes the relationship between students' socioeconomic backgrounds and their academic performance using Python.

The analysis explores how family income, parental education, educational resources, attendance, and study habits relate to students' academic outcomes.

## Objectives

- Understand the structure and characteristics of the dataset.
- Clean and preprocess the data using Pandas.
- Perform numerical operations using NumPy.
- Explore patterns and relationships in the dataset.
- Create meaningful visualizations using Matplotlib and Seaborn.
- Present findings through a data story and final project report.

## Dataset

**Dataset Name:** Grade Prediction Based on Socioeconomic Factors

**Source:** [Kaggle Dataset](https://www.kaggle.com/datasets/chaitanyajamble/grade-prediction-based-on-socioeconomic-factors)

**Dataset Size:** 12,025 rows and 29 columns (as initially inspected).
